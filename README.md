# bible-audio

Аудиофайлы Библии (Синодальный перевод) для Telegram Mini App чтения/прослушивания Библии.

## Структура

```
{slug}/{bb}/{cc}.mp3
```

- `slug` — версия озвучки (например, `syn-bondarenko`)
- `bb` — номер книги, 2 цифры (`01`–`66`)
- `cc` — номер главы, 2 цифры (`01`–`150`)

Пример: `syn-bondarenko/01/01.mp3` — Бытие, глава 1.

Доступ через raw CDN:

```
https://raw.githubusercontent.com/maksjermy123/bible-audio/main/syn-bondarenko/01/01.mp3
```

raw.githubusercontent.com отдаёт CORS `*` и поддерживает Range — прямое стриминг-воспроизведение и перемотка работают.
